# Dream Way DMC – B2B Agent App (Expo / React Native)

Run:
    npm install
    npx expo install --fix     # aligns native package versions with your Expo SDK
    npx expo start             # scan the QR with Expo Go

Screens: Home, Packages (filter), Package detail, Quote request (email/WhatsApp), About & Contact.
Content comes from the Dream Way company profile PDF (src/data.ts). Brand colors in src/theme.ts.
